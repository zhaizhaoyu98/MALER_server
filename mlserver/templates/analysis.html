Parameters of


One-Click Analysis: The model is built with the default parameters and the data is analyzed using all the models provided.

Customized Analysis: Users can choose to specify models and parameters to personalize the data.

Validation: The default design uses repeated 5-fold outer validation (2 repeats) and 3-fold inner tuning. Classification is optimized by balanced accuracy, regression by R², and survival by concordance index. Splits are reduced automatically only when the cohort is too small.

Complete parameter record: All estimator classes, defaults, scaling requirements and searched values are available in the versioned machine-readable method registry.
